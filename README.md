# 日常思考實驗室

把抽象的思考工具變成生活中用得上的小練習。這個繁體中文網站從日常情境出發，介紹機會成本、第二層思考等概念；每篇都有解釋、三步練習和反思問題。首頁可搜尋文章並依主題篩選。

本專案同時示範如何用 [AGENTS.md](AGENTS.md) 記錄共同規則，讓未來的 AI 或協作者依相同結構繼續擴充，而不必每次重新描述設計、檔名、內容格式及測試方式。

## 使用方式

不需要安裝套件或建置工具，下載專案後直接用瀏覽器開啟 `index.html` 即可。首頁卡片會連至 `pages/` 中的文章。網站使用相對路徑，可部署在 GitHub Pages 的專案子路徑。

```text
.
├── AGENTS.md
├── README.md
├── index.html
├── pages/
│   ├── opportunity-cost.html
│   └── second-order-thinking.html
└── assets/
    ├── style.css
    └── script.js
```

## 如何新增內容

請 AI 先閱讀 `AGENTS.md`，再指定主題，例如：「依照專案規則新增一篇關於確認偏誤的文章，並更新首頁。」AI 可以複製既有文章，按固定段落撰寫內容，使用小寫英文連字號命名，在首頁新增對應卡片，沿用共用視覺，最後檢查連結、搜尋、篩選、手機排版與鍵盤操作。詳細流程與驗收清單都在 [AGENTS.md](AGENTS.md)。

## 發布到 GitHub Pages

1. 將專案檔案上傳至 GitHub 儲存庫的預設分支，確認 `index.html` 位於儲存庫根目錄。
2. 在儲存庫的 **Settings → Pages**，選擇從分支部署（Deploy from a branch），選取預設分支及 `/ (root)`，儲存設定。
3. 等待部署完成，使用 Pages 設定頁顯示的網站連結開啟首頁，並測試文章、搜尋和返回連結。

網站與文字內容以學習用途製作；新增外部資料時請標明來源並確認使用權限。
